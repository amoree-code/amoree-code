## About me

I'm **Ameer Abdulkareem Jabbar Lami**, a front-end-focused full stack developer based in **Baghdad, Iraq**, with **2 years** of experience building production web applications for government, enterprise and SaaS products.

My work sits where data scale meets usability: dashboards serving **1.5M+ records** and **500K+ users**, a real-time support platform integrated into **10+ production platforms**, and interfaces that work natively in **Arabic, English, Sorani and Kurmanji**.

- 🏢 **Front-end Developer at StarSphere** — admin dashboards and landing pages for the company's client portfolio
- 🧩 **Focus areas:** large-dataset table UIs, role-based access control, real-time WebSocket features, multi-tenant data isolation
- 🌍 **RTL-first by default** — i18n is planned from the first commit, not retrofitted
- 🌱 **Currently deepening:** back-end engineering with NestJS — data modeling, auth, and module boundaries
- 🤖 **Building [Ocean](https://github.com/amoree-code/ocean)** — a local-first control layer for AI coding agents
- 🗣️ Arabic (native) · English (working proficiency)
